## 🎮 About The Project

**APEX ESPORTS** is a full-stack esports tournament management platform built for competitive gaming communities.

The platform provides a complete ecosystem for players, teams, tournament organizers, and administrators.

It combines a modern esports-focused user interface with a powerful backend, real-time communication, automated tournament workflows, analytics, and centralized administration.

### The platform includes

- 🏆 Tournament management
- 👥 Player & team registration
- 🎯 Match management
- ⚡ Real-time match updates
- 📊 Automated leaderboards
- 📈 Admin analytics
- 🔐 JWT authentication
- 🔑 Google authentication
- ☁️ Cloudinary media management
- 📧 Email communication
- 🛡️ Role-based administration
- 📱 Responsive user experience

# ✨ Features

## 🏆 Tournament Management

Administrators can create and manage complete esports tournaments.

- Create tournaments
- Edit tournament information
- Configure tournament rules
- Set tournament schedules
- Configure entry fees
- Configure prize pools
- Manage tournament status
- Open/close registrations
- Manage registered teams
- Manage registered players

---

## 👤 Player Portal

Players get a dedicated esports experience.

### Player Features

- User registration
- User login
- Google authentication
- Player profile
- Tournament discovery
- Tournament registration
- Team creation
- Team management
- Match tracking
- Tournament history
- Leaderboard tracking
- Notifications
- Real-time updates
